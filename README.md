# cocopalu

スマホでの使いやすさにこだわった、約3人用のパル風手書き共有カレンダーWebアプリです。

## ✨ 特徴
- **手書きでメモ**：各日をタップすると専用の縦長キャンバスが開き、手書きで予定やメモを書き込めます（4色のペン、1つ戻る、全消去機能つき）。
- **更新ボタンで同期**：Firebase Firestoreを使用し、URLを共有したメンバー間で書き込みが同期されます。
- **スマホ最適化（PWA対応）**：iPhoneのホーム画面に「cocopalu」として追加でき、フルスクリーンで快適に操作できます。
- **日本の祝日表示**：2025年〜2028年の祝日データに対応しています。

## 🚀 使い方
1. アプリにアクセスすると、URLのハッシュ（`#`以降）に自動で固有のIDが生成されます。
2. 右上の**共有ボタン**からURLをコピーし、一緒に使いたい人に送ります。
3. 日付をタップして手書きで予定を書き込み、「OK」を押すと自動でクラウドに保存されます。

## 🛠 技術スタック
- Frontend: HTML5 (Canvas), Tailwind CSS, JavaScript (ES Modules)
- Backend: Firebase Firestore (v10 Modular SDK)
- Hosting: GitHub Pages
